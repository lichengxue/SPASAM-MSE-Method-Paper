# SPASAM-MSE Method Paper

This repository contains materials associated with the manuscript:

**SPASAM-MSE: a generalised spatial management strategy evaluation framework for exploring the impacts of spatial structure on stock assessments and management outcomes**

The purpose of this project is to provide open access to simulation code, figures, and manuscript drafts supporting development and evaluation of the **SPASAM-MSE** framework, a generalized tool for conducting spatially-explicit management strategy evaluation (MSE) in fisheries science.

## Repository Contents

- **Cover_Letter.Rmd / Cover_Letter.pdf** – Cover letter for journal submission.
- **SPASAM_MSE_reviewer_comments.Rmd / .pdf** – Reviewer responses and manuscript changes.
- **Method_Paper_Plot.R** – R code to reproduce key figures used in the manuscript.
- **SPASAM-MSE-Final.pdf / .docx** – Final manuscript and supplementary materials.
- **Plots and Figures** – Image files used in the manuscript (e.g., `Main.png`, other figure panels).

## Overview

**SPASAM-MSE** (Spatial Population Assessment and Strategic Analysis Model – Management Strategy Evaluation) is a flexible framework designed to:

- Simulate spatially structured fish populations with movement among regions.
- Support closed-loop management strategy evaluation with multiple user-defined harvest control rules (HCRs) and spatial scenarios.
- Explore how spatial structure and movement dynamics influence stock assessment and management outcomes.
